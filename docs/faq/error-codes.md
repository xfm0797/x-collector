# 发布失败错误码 1001 是什么？

**1001 = CMS 连接失败**：无法访问目标站点的 XML-RPC 接口。

排查步骤：

1. 在浏览器直接访问 `站点地址 + API 路径`（如 `https://yourblog.com/xmlrpc.php`），应返回 XML 描述；
2. 检查网络连通性或代理设置；
3. WordPress 站点确认安全插件未禁用 XML-RPC。

# 发布失败错误码 1002 是什么？

**1002 = CMS 认证失败**：凭证被拒绝。

- WordPress：必须使用「应用密码」而非登录密码，且站点需 HTTPS；
- Typecho / Z-Blog：确认用户名与登录密码正确，账户未被禁用。

# 正文提取为空（2002）怎么解决？

页面大概率是 JS 渲染（SPA）。解决方式：

1. 在采集源中为该站点配置「正文选择器」（CSS 选择器）；
2. 优先使用该站点的 RSS 订阅源；
3. 单页采集时观察页面结构，把正文容器的 class 填入选择器。
