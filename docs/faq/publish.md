# 如何配置 WordPress 自动发布？

1. 「发布管理 → CMS 连接 → 添加连接」，CMS 类型选 WordPress；
2. 站点地址填 `https://yourblog.com`，API 路径 `/xmlrpc.php`；
3. 用户名填登录名，密码填 **应用密码**：后台「用户 → 个人资料 → 应用密码 → 添加新应用密码」；
4. 点击「测试」，提示连接成功后即可批量发布。

注意：应用密码仅支持 HTTPS 站点；若测试返回 fault，多为密码错误或 XML-RPC 被安全插件禁用。

# 伪原创功能怎么用？

1. 「设置 → 伪原创」开启并保存（或在文章编辑器中打开「改写设置」）；
2. 打开一篇文章，点击「伪原创」→「预览改写」，双栏对比原文与改写效果；
3. 满意后点击「应用到文章」，不满意可调整比例后重新预览；
4. 开启后新采集的文章会自动执行改写。

代码块、表格、标题与图片永远不会被改写。
