# 采集时遇到 403 错误怎么办？

**原因**：目标网站检测到爬虫请求，触发了反爬机制。

**解决方案**：

1. 检查 User-Agent 是否设置为真实浏览器（本工具默认随机轮换真实 UA）；
2. 降低请求频率，保持 2-5 秒随机间隔；
3. 程序已自动附加完整请求头（Referer、Accept、Sec-Fetch-* 等）；
4. 在「设置 → 代理」配置代理 IP；
5. 失败自动指数退避重试已内置，无需手动干预。

# 为什么搜索引擎返回的结果很少或为空？

常见原因与对策：

- **被搜索引擎反爬拦截**：增大请求间隔、更换搜索引擎；
- **Google 需要代理**：国内网络在「设置 → 代理」中配置可用代理；
- **关键词过冷门**：换用更宽泛的关键词，或改用 Bing；
- **站点限定过窄**：`site:` 限定会大幅缩小结果范围，确认域名拼写正确。

# 如何设置定时采集任务？

在关键词任务编辑中把「轮询间隔（分钟）」设置为大于 0 的值（如 120 表示每 2 小时一次）。应用运行期间会按间隔自动执行；配合「启用」开关可临时暂停任务。
