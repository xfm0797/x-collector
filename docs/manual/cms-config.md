# CMS 连接配置

## 7.1 连接管理

「发布管理 → CMS 连接」提供完整的连接生命周期管理：

- **添加 / 编辑**：填写连接名称、CMS 类型、站点地址、API 路径与凭证；
- **测试**：调用 `blogger.getUsersBlogs` 验证连通性与凭证（无需真实发布）；
- **删除**：单条删除（关联的发布记录会保留）；
- **启用 / 禁用**：禁用的连接不会出现在发布目标中。

## 7.2 密码与安全

- 密码使用应用级加密混淆后存储在本地 SQLite，前端列表接口 **不会返回密码明文**；
- WordPress 推荐使用「应用密码」，可随时在站点侧单独吊销；
- 所有发布请求直连目标站点，枫铃采集器不经过任何第三方服务器；
- 建议站点启用 HTTPS，XML-RPC 凭证在明文 HTTP 下存在被窃听风险。

## 7.3 各平台 API 路径速查

| CMS | API 路径 | 凭证 |
|-----|----------|------|
| WordPress | `/xmlrpc.php` | 应用密码 |
| Typecho | `/action/xmlrpc` | 登录密码 |
| Z-Blog | `/zb_system/xml-rpc/index.php` | 登录密码 |
