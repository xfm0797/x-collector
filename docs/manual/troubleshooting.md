# 故障排除

## 8.1 常见错误码

| 错误码 | 名称 | 快速解决 |
|--------|------|----------|
| 1001 | CMS 连接失败 | 核对站点地址与 API 路径 |
| 1002 | CMS 认证失败 | WordPress 使用应用密码 |
| 2001 | 采集请求失败 | 降低频率 / 配置代理 |
| 2002 | 正文提取失败 | 配置自定义 CSS 选择器 |
| 3001 | 数据库写入失败 | 检查磁盘空间并重启 |

## 8.2 网络问题

- **搜索引擎返回空结果**：多为被反爬拦截。增大请求间隔、更换搜索引擎或配置代理。
- **Google 无法访问**：国内网络需配置代理。
- **请求全部超时**：检查代理设置是否正确，或临时关闭代理测试。

## 8.3 解析问题

- **正文提取为空**：页面可能是纯 JS 渲染（SPA），尝试配置自定义选择器，或改用该站点的 RSS 源。
- **采集到乱码**：程序已支持 GBK/UTF-8 自动识别，仍有乱码请通过 GitHub Issue 反馈站点 URL。
- **图片丢失**：部分站点图片有防盗链，导出 Hexo 后可能无法显示，v1.3 将支持图片本地化。

## 8.4 发布失败处理

1. 先用「测试连接」排除凭证问题；
2. 查看发布记录中的具体错误信息；
3. WordPress 认证失败最常见原因是使用了登录密码而非应用密码；
4. Typecho / Z-Blog 需确认 XML-RPC 扩展已开启；
5. Hexo 导出失败请确认目录存在且有写权限。
