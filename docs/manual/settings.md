# 系统设置

## 7.1 采集设置

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 请求超时 | 30 秒 | 单次请求超时时间 |
| 并发数 | 3 | 同时进行的请求数 |
| 请求间隔 | 2-5 秒 | 每次请求前的随机延迟区间 |
| 失败重试 | 3 次 | 指数退避重试（0.8s → 1.6s → 3.2s） |
| User-Agent | 随机轮换 | 可固定为自定义 UA |

## 7.2 代理设置

支持 HTTP / SOCKS5 代理（如 `http://127.0.0.1:7890`、`socks5://127.0.0.1:1080`），采集与发布请求均会走代理。

## 7.3 反爬设置

内置反爬能力：

- **UA 轮换**：6 个真实浏览器 UA 随机切换；
- **请求头完整性**：Accept / Accept-Language / Referer / Sec-Fetch-* 全套浏览器头；
- **Cookie 管理**：自动保存并携带 Cookie；
- **频率控制**：随机延迟 + 失败退避；
- 遇到 403 时优先增大请求间隔，或配置代理。

## 7.4 设置导入导出

「设置」页右上角支持将全部设置导出为 JSON 备份，或从备份恢复。CMS 密码包含在导出文件中，请妥善保管。
