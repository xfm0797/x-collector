# 内容清洗

## 4.1 广告过滤

自动移除基于类名 / ID 黑名单的广告元素（`ad`、`ads`、`advert`、`sponsor`、`google_ads` 等），以及导航栏、页脚、侧边栏、评论区、分享栏、推荐位等非正文元素。

## 4.2 图片处理

- **保留原链接**（当前默认）：图片链接转为绝对地址后保留。
- 图片处理策略可在采集源的自定义规则中扩展（下载到本地 / 图床将在 v1.3 版本提供）。

## 4.3 格式优化

- 相对链接自动转绝对链接；
- HTML 实体解码（`&lt;` → `<` 等）；
- 合并连续空白行、压缩连续 `<br>`；
- HTML 自动转换为 Markdown（代码块、表格、图片均可保留）。

## 4.4 自定义规则

在采集源的「移除元素选择器」中按需追加站点专属的清理规则，多个选择器用逗号或换行分隔。
