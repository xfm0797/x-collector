# 采集源管理

## 3.1 RSS 订阅源

「采集源」页面点击「添加采集源」，类型选择 RSS，填入订阅地址（如 `https://example.com/feed.xml`）。采集时会：

1. 解析 RSS / Atom 中的全部条目链接；
2. 逐篇抓取正文（自动智能提取）；
3. 三重去重后入库。

## 3.2 单页采集

两种方式：

- 「文章库」页面点击「单页采集」，输入 URL 立即采集一篇；
- 采集源类型选择「网页采集」，将固定页面作为持续跟踪的源。

## 3.3 站点地图采集

点击「从站点地图发现」输入 `sitemap.xml` 地址，可先预览发现的全部链接；也可将 sitemap 添加为采集源，每次采集会抓取前 30 个链接（避免单次任务过长）。

## 3.4 自定义选择器

当智能提取效果不理想时，可为采集源配置 CSS 选择器：

| 字段 | 说明 | 示例 |
|------|------|------|
| 正文选择器 | 正文容器 | `div.article-content` |
| 标题选择器 | 标题元素 | `h1.title` |
| 移除元素 | 需剔除的广告等（逗号分隔） | `div.ad, div.related` |

常见站点的适配已内置（知乎、CSDN、博客园、掘金、微信公众号），无需手动配置。

## 3.5 可视化选择器

无需手写 CSS 选择器：编辑采集源时，点击「正文选择器」「标题选择器」「移除元素选择器」旁的「可视化选择」按钮：

1. 输入一篇示例文章的 URL，点击「加载页面」；
2. 左侧展示页面 DOM 树（标注标签、id、class 与文本量）；
3. 点击目标节点，右侧自动生成 CSS 选择器并显示文本预览；
4. 点击「测试选择器」实时验证匹配数量与命中内容（未命中时可改用完整路径）；
5. 点击「使用此选择器」回填表单。

## 3.6 模板库

点击采集源页面的「模板库」按钮，可一键应用内置模板：

- **采集源模板**：知乎、CSDN/博客园、掘金、微信公众号等站点的成品选择器配置，以及阮一峰周刊、少数派、InfoQ 等 RSS 订阅源；
- **清洗规则模板**：广告清理、相关推荐清理、评论互动清理、导航页脚清理、深度清理（全量规则），可叠加追加到移除列表。

CMS 连接配置同样支持模板快选（WordPress / Typecho / Z-Blog / 草稿模式），在发布管理的连接表单顶部选择即可。
