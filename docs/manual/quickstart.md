# 快速开始

## 1.1 安装与启动

- **Windows**：下载安装包（.msi / .exe）后双击安装，桌面将出现「枫铃采集器」图标。
- **macOS**：下载 .dmg，将应用拖入「应用程序」文件夹，首次启动时右键选择「打开」。
- **Linux**：下载 .AppImage，赋予执行权限后运行。

数据存储在系统应用数据目录（Windows 为 `%APPDATA%/com.xfm.x-collector`），卸载重装不会丢失文章库。

## 1.2 首次配置向导

首次使用建议完成以下配置（均可在「设置」页面随时修改）：

1. **采集设置**：请求间隔默认 2-5 秒随机延迟，可按目标站点强度调整。
2. **伪原创设置**：默认关闭；如需启用，在「设置 → 伪原创」中开启并调整比例。
3. **发布设置**：配置默认发布方式与 Hexo 导出目录，或在「发布管理」中添加 CMS 连接。

## 1.3 第一条采集任务

1. 进入「关键词采集」页面，点击「添加关键词」。
2. 填写关键词（例如 `Rust 教程`），搜索引擎选择「百度」，采集深度 3 页。
3. 点击任务右侧「采集」按钮，观察进度条与日志。
4. 采集完成后进入「文章库」查看结果，重复文章会自动去重跳过。
5. 在文章编辑器中预览 / 编辑 Markdown 内容。
6. 进入「发布管理」，选择文章批量发布到 Hexo 或 CMS。
