# 枫铃采集器用户手册

欢迎使用枫铃采集器（x-collector）！这是一款集 **关键词采集、采集源管理、内容清洗（含伪原创）、多平台发布** 于一体的桌面工具。

## 核心功能一览

| 模块 | 说明 |
|------|------|
| 关键词采集 | 通过百度 / Google / Bing / 搜狗按关键词批量发现并采集文章 |
| 采集源管理 | RSS 订阅、单页采集、站点地图批量采集 |
| 内容清洗 | 自动移除广告 / 导航 / 侧边栏，链接绝对化，格式规范化 |
| 伪原创 | 同义词替换、句子改写、段落重排、首尾段重写 |
| 发布管理 | Hexo 导出、WordPress / Typecho / Z-Blog 自动发布（XML-RPC） |
| 帮助系统 | 用户手册、配置示例、FAQ、全文搜索 |

## 使用建议

1. 新用户请先阅读「快速开始」章节，3 步完成第一条采集任务。
2. 采集技术类文章时，代码块与表格会被完整保留，不会被伪原创破坏。
3. 遇到问题可在帮助中心搜索，或按错误码在「故障排除」章节查找解决方案。
