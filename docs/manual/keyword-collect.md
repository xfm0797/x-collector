# 关键词采集

## 2.1 添加关键词

进入「关键词采集」页面，点击「添加关键词」按钮：

- **关键词**：必填，建议使用明确的主题词（如 `Tauri 开发实战`）。
- **分组**：按主题分组管理，便于批量查看。
- **站点限定**：填入域名（如 `csdn.net`），查询会自动附加 `site:` 限定搜索范围。

## 2.2 搜索引擎配置

支持四种搜索引擎：

| 引擎 | 特点 |
|------|------|
| 百度 | 中文内容覆盖最全，反爬较强 |
| Bing | 国际 + 中文均衡，反爬较宽松 |
| Google | 内容质量高，国内需代理 |
| 搜狗 | 微信公众号内容入口 |

> 提示：使用 Google 建议在「设置 → 代理」中配置代理；百度 / 搜狗会返回跳转链接，程序会自动跟随重定向获取真实 URL。

## 2.3 匹配规则设置

- **标题匹配**（默认）：仅采集标题包含关键词的结果，速度快。
- **全文匹配**：抓取页面后检查正文是否包含关键词，更准但更慢。
- **标题或全文**：两者任一命中即入库。
- **精确匹配**：忽略空格的完整包含匹配。

## 2.4 定时任务配置

关键词任务的「轮询间隔（分钟）」大于 0 时即为定时任务。设置后每次应用启动会按间隔自动执行采集，适合跟踪热点主题。

## 2.5 去重策略说明

三重去重机制，命中任意一条即跳过：

1. **URL 去重**：URL 的 SHA-256 哈希已在库中。
2. **标题相似度去重**：与已有文章标题编辑距离相似度 ≥ 85% 视为重复（跨源也能识别）。
3. **内容指纹去重**：正文前 500 字（去空白）的 SHA-256 指纹相同视为重复。
