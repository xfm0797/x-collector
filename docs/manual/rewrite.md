# 伪原创

> 重要：伪原创不会触碰 **代码块、表格、标题与图片**，技术文章的结构与代码完整保留。

## 5.1 同义词替换

内置 120+ 组中文同义词词库，按配置比例（默认 30%，可调 10%-50%）对正文词语进行同义替换。可在「设置 → 伪原创」调整。

## 5.2 句子改写

按比例（默认 20%）对句子执行三种变换：

1. **连接词插入**：句首插入「然而 / 因此 / 值得注意的是」等连接词；
2. **子句换序**：逗号分隔的 2-4 个子句随机重排；
3. **长句拆分**：超过 60 字的长句在中间断开为两句。

## 5.3 段落重排

开启后，中间段落随机打乱顺序，**首段与尾段保留原位**，保证文章整体逻辑可读。

## 5.4 首尾段重写

使用内置模板库重新生成开头与结尾（原段落核心内容会附在模板之后），适合批量内容差异化。

## 5.5 自定义词库

在「设置 → 伪原创 → 词库管理」导入自定义词库，JSON 格式：

```json
[
  ["快速", "迅速", "敏捷"],
  ["重要", "关键", "核心"]
]
```
